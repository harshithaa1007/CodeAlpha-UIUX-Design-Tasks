Task 4 – Mini Project: Prototype Design

This task focuses on creating a clickable prototype for the LearnX educational mobile application as part of the CodeAlpha UI/UX Design Internship.

Project Overview
LearnX is an educational mobile application designed to provide users with an easy and engaging way to explore courses and access video lessons.

The prototype demonstrates the main user flow from launching the application to logging in, exploring courses, viewing course details, accessing video lessons, and managing the user profile.

Prototype Screens
1. Splash Screen
2. Login
3. Sign Up
4. Home
5. Course Details
6. Video Lesson
7. Profile
