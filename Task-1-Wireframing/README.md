# Task 1 – Wireframing & Low-Fidelity Design

This task focuses on creating wireframes and a low-fidelity design for an educational mobile application as part of the CodeAlpha UI/UX Design Internship.

## 🎨 Project Overview

The wireframes represent the main screens and user flow of the application, from launching the app to accessing courses and video lessons.

## 📱 Wireframe Screens

1. Splash Screen
2. Login
3. Sign Up
4. Home
5. Course Details
6. Video Lesson
7. Profile

## 🛠️ Tool Used

- Figma

## 📄 Deliverables

- 7 low-fidelity wireframe screens
- Combined PDF of the wireframes
- Figma design link
