# Task 2 – High-Fidelity UI Design

This task focuses on converting the low-fidelity wireframes into a high-fidelity UI design as part of the CodeAlpha UI/UX Design Internship.

## 🎨 Project Overview

The wireframes were transformed into polished UI screens by applying colors, typography, buttons, icons, images, and other visual elements while following UI/UX design principles.

## 📱 UI Screens

1. Splash Screen
2. Login
3. Sign Up
4. Home
5. Course Details
6. Video Lesson
7. Profile

## 🛠️ Tool Used

- Figma

## 📄 Deliverables

- 7 high-fidelity UI screens
- Combined PDF of the UI designs
- Figma design link
